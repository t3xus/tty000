# tty000

A TTY in this tab. https://tty000.com/

Free. MIT License. Serial workbench in the browser.

## Install

The package name is `tty000`. pip and npm pull it from tty000.com. Homebrew taps t3xus/tty000.

```bash
pip3 install tty000 --extra-index-url https://tty000.com/simple/
npm install -g tty000 --registry https://tty000.com/npm/
brew install t3xus/tty000/tty000
```

Then:

```bash
tty000 --helper
```

Open http://127.0.0.1:7682/

Chrome can skip the helper and use Web Serial on https://tty000.com/

Source zip: https://tty000.com/tty000.zip
